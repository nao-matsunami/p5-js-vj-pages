# p5.js VJ Site

p5.jsで生成するVJ素材のサンプルを毎日公開する静的サイトです。

GitHub Pages shows the live p5.js sketch preview. Saleable MP4 / alpha MOV masters can be recorded in-browser for samples or rendered separately on the Mac mini with fixed timing.

## Commands

```sh
npm run daily:update
npm run publish:pages
```
